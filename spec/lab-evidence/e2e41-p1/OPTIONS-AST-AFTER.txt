# own evidence:
#   1. filestmt_opt_keys -- the nine FILE statements now accept KEYED, DIRECT, PRINT,
#      PAGESIZE, LINESIZE (the five words P0 found missing from DR's own objects),
#      SEQUENTIAL (documented in the manual's file-attribute list, p.60, but in no
#      sampled object), and KEYTO/INTO/FROM (DR-compiled READ/WRITE sources).  The
#      GET/PUT/EDIT list `ioopt_keys' is UNCHANGED on purpose: the EDIT arm eats FROM
#      itself, so a shared widened list would swallow every `EDIT ... FROM' source.
#   2. a strict tail check on the nine FILE statements: an unrecognised word is now a
#      loud [TBD] refusal instead of being re-read as the following statement.
