# the PUSH H words (E46E4 above has six, and its COMMON is /F/).  Instruction boundaries come
# from a linear decode with tools/dis80.py's length table over a bitstream replay that keeps the
# RELOC attached to each byte -- the same discipline [C125]/[C137] established, and the reason
# COPYLPT's blocks are complete here and were truncated in tools/reldump.py's text.
#
# What this file is evidence FOR, in [C282], [C285], [C286] and [C287]:
#   * `PUSH B ; INX SP' at the head of a titleless block -- the title length is pushed as a
#     WORD and the low half thrown away, so the argument is one byte.  This is why a titleless
#     open builds w2 out of B (`MOV H,B / MOV L,B', the DB 60 / DB 68 pairs below) while a
#     TITLED open resets it with `LXI H,0000': after INX SP, B is still live and still holds
#     the length, so the two forms cannot be normalised to one instruction sequence.
#   * the block ENDS at `CALL ?OIOOP' -- no POP follows it in any block here, so ?OIOOP's
#     callee cleans the stack, which is the same convention the 6-byte CLOSE block implies.
#   * w1 per probe, which is where the option-word table in the note comes from.
